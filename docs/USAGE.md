# 使用指引

## 第一次打开

1. 启动后没有主窗口，也没有 Dock 图标，只有微信旁边会出现一个深色小卡片。微信没开、或者没有点开任何会话时，卡片自动隐藏。
2. 第一次判断要下载模型权重（约 850 MB），卡片上显示"模型加载中…"，之后每次启动加载约 30 秒。
3. 系统会向"Laya Chat"请求两项权限，都要允许：
   - **屏幕录制**：用来分辨一条消息是你发的还是对方发的（按气泡颜色）。
   - **辅助功能**：用来读微信窗口里的会话名、消息文字和输入框内容。
   没弹出来的话，到 系统设置 → 隐私与安全性 里手动加上"Laya Chat"，然后退出重开。

## 日常怎么用

- **打字前**看好感度和待办，知道对方现在什么状态、有什么事悬着。
- **打完字停一秒**，看"这条发出去"那一段。改字它就重算。
- **拿不准就点求助**：把对话、草稿和上面的判断交给本机的 Claude 或 Codex，半分钟后给一句评价和三条改写，每条有"填入"和"复制"。填入只是放进输入框，替换你写的，**不会发送**。改动草稿、对方来新消息、切换会话，这些建议都会自动清掉。
- **发送永远由你按回车。** 程序没有任何发送的能力。

## 关系设定

默认把所有人当"朋友"。给某个会话单独设定，编辑 `~/.laya-chat/config.json`：

```json
{
  "relationships": {
    "小王": "对方是我的伴侣",
    "张经理": "对方是我的同事"
  }
}
```

键是微信里显示的会话名，值是一句话。改完重启程序生效。

## 数据都在哪、怎么删

全部在 `~/.laya-chat/`：

| 文件 | 内容 | 作用 |
|---|---|---|
| `config.json` | 配置 | |
| `history/<会话名>.jsonl` | 程序看到过的消息 | 供好感度判断，最多每个会话 500 条 |
| `feedback.jsonl` | 你发出的每一条 + 对方的回复 + 发送前后的好感度 + 当时的预测 | 以后用真实聊天再训练 |

不想记录：`config.json` 里 `"keep_history": false`。清空：`python -m laya_chat --clear`，或者直接删掉这个目录。除了求助按钮，程序不联网、不把聊天内容发给任何地方。

## 常见问题

**卡片不出现。** 依次检查：微信是否点开了一个会话；两项权限是否都给了"Laya Chat"；前台运行看报错：`cd <安装目录> && .venv/bin/python -m laya_chat`。

**我方和对方分反了。** 分辨靠气泡颜色，目前只认微信默认配色（我方绿色）。换过聊天背景或气泡皮肤会失效。

**多显示器。** 卡片跟着微信所在的屏幕走，底边和输入框底边平齐，右边放不下就放左边。

**群聊。** 按一对一处理，"对方"是群里所有人的合集，判断会偏。

**判断不准。** 见 README 里"模型质量"一节。没有用微调权重时，卡片上的数字接近随机。

**卸载。** `installer/make_app.sh --remove` 删掉 .app 和登录项，再删安装目录和 `~/.laya-chat/`。
